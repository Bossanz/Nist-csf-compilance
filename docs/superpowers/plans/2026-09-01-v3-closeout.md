# V3 Local Workflow Closeout Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Execute this plan inline with a fresh verification gate after each change.

**Goal:** Verify and close the V3 local-development workflow without adding V4 features or online/production infrastructure.

**Architecture:** Preserve the current Next.js frontend, Go HTTP API, PostgreSQL schema, Docker Compose runtime, and server-side RBAC. Start with full baseline checks, repair only reproducible V3 defects, then rerun the complete verification and document the final boundary.

**Tech Stack:** Next.js 16, React 19, TypeScript, Vitest, Go 1.24, PostgreSQL 16, Docker Compose, PowerShell.

**Spec:** `PRODUCT.md`, `README.md` sections `System workflow`, `Roles and permissions`, `Implemented features`, and `Not included in the current local slice`.

## Global Constraints

- Keep the scope limited to the V3 local workflow; do not implement V4 ideas, AI, or online/production infrastructure.
- Preserve the existing role model: Counselor Admin, Counselor, Org Admin, Assessor, Reviewer, Viewer, and Auditor.
- Preserve the workflow order: Scope -> Stakeholder assessment -> Reviewing/Approved -> Finalize -> Remediation -> Report/Audit.
- Keep authorization enforced by the API; UI visibility is not a security boundary.
- Do not stage or modify pre-existing `output/`, `tmp/`, `web/AGENTS.md`, or `web/CLAUDE.md` changes unless a verification result requires a targeted source change.
